## 🧠 Problem Statement  

Managing an e-commerce platform without automation leads to:

- Difficulty in managing products and inventory  
- Lack of centralized order tracking  
- Poor admin experience  
- Security risks without authentication  
- Time-consuming manual operations  

---

## 💡 Solution  

This project provides a centralized admin dashboard that:

- Enables efficient product and inventory management  
- Tracks orders in real-time  
- Secures the system using authentication and authorization  
- Provides a responsive and user-friendly interface  
- Supports scalability for future enhancements  

---

## 🏗️ System Architecture  

Frontend (React + Tailwind CSS)  
↓  
Backend (Node.js + Express)  
↓

## ✨ Key Features  

### Product Management  
- Add, update, and delete products  
- Upload and manage product images  
- Organize products using categories  
- Real-time product updates  

---

- Update order status (Pending, Shipped, Delivered)

## ⚙️ Installation  

### Clone Repository  
```bash
git clone https://github.com/harshitasurana/E-Dashboard.git
cd E-Dashboard
```
## Backend Setup

```
cd Backend
npm install
```

## Create .env file:
```
PORT=5000
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret_key
```

## Frontend Setup

```
cd Frontend
npm install
npm run dev
```
## Run Backend
```
cd Backend
npm start
```
## 🌍 Access

Frontend: http://localhost:5173

Backend: http://localhost:5000
